# README técnico – Proyecto Temas Digitales Avanzados 2025  
**Fecha:** 06/12/2025  

Este documento describe la estructura técnica del proyecto, las simulaciones implementadas y el uso de los scripts asociados. El foco principal está en el procesador tipo RISC-V simplificado, el entorno FemtoRV y la integración del multiplicador y periféricos básicos, con un enfoque claro y reproducible para simulación.

---

## 1. Estructura general del repositorio

- rtl_new/
- tb_new/
- femtoRV/
- VLSI/
- scripts/
- sim/
- program.mem

Cada carpeta contiene módulos RTL, testbenches, scripts de simulación y modelos que permiten evaluar tanto el diseño propio como los modelos de referencia basados en FemtoRV.

## 2. Componentes principales del diseño

### 2.1 ALU32
Unidad aritmético-lógica de 32 bits con soporte para operaciones requeridas por el perfil RV32I: suma, resta, AND, OR, XOR, comparaciones y desplazamientos. La salida incluye indicadores de cero, acarreo, signo y overflow.

### 2.2 Registro de 32 x 32 bits (RegFile32)
Banco de registros con dos puertos de lectura y un puerto de escritura. El registro x0 está cableado a cero, respetando la especificación RISC-V.

### 2.3 Decoder32
Decodificador para instrucciones RV32I, obteniendo campos opcode, funct3, funct7, rs1, rs2, rd e inmediatos para todos los formatos (I, S, B, U, J). Produce señales de control como reg_write, mem_read, mem_write, branch, jump, mem_to_reg, alu_src y alu_op.

### 2.4 Bram32
Memoria RAM simple inicializable mediante program.mem. Utilizada como memoria de instrucciones en el SoC mínimo.

### 2.5 SOC_flash
SoC mínimo integrando núcleo Core32, memoria Bram32 e interfaces simples. Permite evaluar el flujo PC → memoria → instrucción → pipeline básico.

## 3. FemtoRV: integración y simulaciones

### 3.1 FemtoRV local
En la carpeta femtoRV/ se encuentra la versión localizada del SoC FemtoRV:

- Módulo top: femto
- Testbench: femto_TB.v
- Salidas observables: LEDS[7:0]

Este testbench simula el flujo completo del procesador, sin periféricos adicionales, permitiendo analizar comportamiento de PC, bus de instrucciones y evolución del programa cargado.

### 3.2 SoC FemtoRV en flujo VLSI de referencia
En VLSI/reference/ttsky25b-femtorv-soc se encuentra un entorno equivalente usado como referencia académica. Incluye:

- test/tb.v y test/tb_dump.v
- Módulo top adaptado a TinyTapeout
- Arquitectura FemtoRV ampliada con periféricos reales y mapa de memoria

Este entorno permite comparaciones entre el diseño propio y el de referencia.

### 3.3 Módulo multiplicador
El multiplicador integrado en versiones del FemtoRV se comporta como periférico mapeado en memoria. Aunque no se simuló como módulo aislado, se evalúa indirectamente en las simulaciones del SoC FemtoRV.

## 4. Scripts de simulación

### 4.1 run_alu32.sh
Compila y simula la ALU de 32 bits.  
Salida: sim/alu32_TB.vcd  

### 4.2 run_regfile32.sh
Simula la operación del banco de registros.  
Salida: sim/regfile32_TB.vcd  

### 4.3 run_decoder32.sh
Simula la decodificación de instrucciones RV32I.  
Salida: sim/decoder32_TB.vcd  

### 4.4 run_soc_new.sh
Simula el SoC mínimo SOC_flash usando program.mem como memoria de instrucciones.  
Salida: sim/SOC_flash_TB.vcd  

### 4.5 run_femto_soc_local.sh
Simula el FemtoRV integrado localmente, mostrando actividad en LEDS.  
Salida: femtoRV/sim/femto_TB.vcd  

### 4.6 run_femtorv_soc_ref.sh
Simula el FemtoRV de referencia en la estructura VLSI.  
Salida: VLSI/sim/femtorv_soc.vcd
